# Gate 4 · Expression Architecture

**Runtime scope:** apply the continuation rule in [SKILL.md](../SKILL.md#runtime-authorization-and-continuation).
A full-briefing request authorizes necessary downstream stages. Stage-local stop/Trial
instructions below bound single-stage development requests; they do not require
fresh user approval during an already authorized briefing.

**Status: WORKING FREEZE.** Use when Gate 4 is explicitly authorized. Specify semantic
representation and attention needs for the established narrative, not decorative
style. Stop before Gate 5 Base Artifact, final visual styling, HTML, motion
choreography and Signature Expression. No component library or schema is required.

## Responsibility and input

How should cognitive relationships be represented so the audience can perceive
them with minimum unnecessary inference?

Use Gate 3's cognitive jobs, sequence/branch/convergence/comparison relationships,
Focus/Synthesis/Return and required context, with Gate 2's authorized endpoint and
upstream evidence scope. Gate 3 determines the necessary viewing path; Gate 4 decides
what must be perceived together or separately within that path. Do not replace an
understanding-only objective with persuasion, or assume every State needs a diagram.
Use the Expression Feasibility Feedback Loop below when expression reveals a
semantic or cognitive failure; do not invent facts to make representation easier.

Expression Architecture decides semantic relationships and attention priorities.
Visual Design later chooses typography, palette, spacing, materials and detailed
composition. A representation decision is not a specification of its final look.

## From cognitive need to representation

For each important State:

1. **Name the relationship the audience must perceive.** Examples include distinction,
   grouping, hierarchy, sequence, comparison, quantity, trend, distribution,
   composition, dependency, association, causality, spatial relationship, uncertainty,
   evidence strength, whole/part and focus/context. This is not a required taxonomy.
   Identify evidence for the relationship itself, not just its endpoints.
2. **Choose a primary Expression Function.** Explain, distinguish, compare, quantify,
   relate, sequence, locate, demonstrate, evidence, synthesize, qualify or emphasize
   are useful descriptions. Add a supporting function only when the main job needs it.
3. **Choose the minimum sufficient Representation Mode.** Options include a direct
   statement, key number, structured text, annotated example, evidence excerpt,
   comparison frame, matrix, timeline, process/flow, system relationship, hierarchy,
   quantitative chart, distribution, map, layered composition or summary synthesis.
   This is an open set. Explain what remembering, matching or inference the choice
   removes. Prefer plain language when it conveys the relationship adequately.
4. **Check the implied claim.** Ask what a viewer could conclude from the structure
   even without reading the caveat. If that conclusion exceeds the evidence, change
   or remove the encoding. A disclaimer cannot repair a contradictory main signal.

Function is the cognitive job; Mode is a means of doing it. Compare does not always
mean a table, a number does not require a chart, and a process does not require arrows.
An aesthetically attractive form is not evidence of semantic fitness.

Judge the audience's decoding burden. If an icon, line or color carries meaning
that this audience must guess, add a direct label, choose an intelligible form or
omit it. Decompose the content first; do not trade interpretation effort for novelty.
Later styling can use [Expression Craft](expression-craft.md) without treating its
reference observations as prescribed forms or evidence of audience benefit.

## Expression Feasibility Feedback Loop

**Difficulty in expression can reveal an upstream cognitive-structure problem.**
After reasonable exploration of suitable representations, diagnose persistent
friction rather than forcing the State into a form. No exhaustive search is needed.

Expression Attempt → Representation Friction → Diagnose Source → Local Repair.

Triggers include competing Primary Signals, excessive context needed to avoid
misreading, impossible focus, burdensome comparison matching, or multiple jobs that
cannot coexist without ambiguity. A meaning that needs extensive explanation can
signal a badly cut cognitive unit. Aesthetic dissatisfaction alone is not a trigger.

| Diagnosed source | Smallest appropriate response |
|---|---|
| Representation Problem | The job and dependencies are clear; reselect the Representation Mode within Gate 4. |
| State Granularity Problem | Separable jobs compete; propose a local State split to the affected Gate 3 path, preserving dependencies, anchors and endpoint. |
| Scene Structure Problem | Separately expressible States still lack clear Focus/Synthesis or dependencies; return the specific Scene problem to Gate 3. |
| Upstream Meaning Problem | Identify the unresolved issue: Cognitive Spine in Gate 2, evidence in Gate 1/source handling, or conflicting Audience Shift in Gate 0. Do not redefine it in Gate 4. |

**Repair locally when possible. Escalate only as far upstream as necessary.**
State the affected node, failed meaning, attempted representation and proposed local
repair briefly; no feedback engine or separate report. If a repair changes user
intent or adopted scope, obtain that choice through the owning Gate. Continue only
independent work while a necessary meaning or evidence issue remains unresolved.
Return to the affected expression after repair; do not reopen the entire project.

## Semantic Encoding boundary

**Every meaningful visual encoding is also a claim.** A relation can be asserted
through position, connection, scale, grouping or emphasis as well as through words.

| Encoding under consideration | Claim to check before adopting it |
|---|---|
| Arrow or connected flow | Is this sequence, dependency, movement or causality? Name the actual relation. Association alone does not warrant a causal path. |
| Before/after pairing | Are these comparable observations of an actual change? Different subjects or states do not establish transformation. |
| Area, length or magnitude emphasis | Is a quantitative magnitude supported with compatible units and basis? Unknown is not zero; importance is not measured size. |
| Categories or group boundaries | Are membership and distinctions established, tentative or overlapping? Do not imply stable classification through an unqualified grouping. |
| Timeline or stages | Are dates and implementation stages supported? Gradual adoption or an undated interval must not become a precise rollout sequence. |
| Map distance or proximity | Is the intended claim geography or relationship strength? Geographic closeness does not prove influence, similarity or dependency. |
| Comparison alignment | Are options compared on the same definitions, scope and status? A proposal's target must not appear equivalent to another option's measured result. |

Narrow the representation, expose the uncertainty at the relevant relation, or do
not encode it. Do not invent numerical confidence or weights for qualitative evidence.
This is a semantic check, not a ban on useful arrows, charts or maps.

## Directness and attention

**Show the relationship directly.** Align the dimensions actually being compared;
do not require recall across isolated descriptions. Keep a part connected to its
whole. Keep consequential interpretation close in meaning to its supporting evidence
and competing explanation, rather than presenting it as an unqualified conclusion.

Define four attention roles without choosing colors, fonts or animation:

- **Primary Signal:** what deserves attention now to complete this cognitive job.
- **Supporting Context:** definitions, comparator, scope or limitations without which
  the signal would mislead. These must remain available with the claim.
- **Suppressed Detail:** accurate but currently nonessential detail that can be
  deferred. Never suppress counterevidence or uncertainty that changes the conclusion.
- **Return Anchor:** the evidence, object or concept that Gate 3 requires later;
  preserve its identity, scope and status when it returns.

Focus may isolate a distinction while retaining its essential context. Synthesis
makes relationships among established parts directly available. Return reintroduces
the needed anchor without forcing viewers to reconstruct earlier material.

Aim for **minimum sufficient representation**, not the fewest words or objects.
If everything competes, clarify priority or revisit State granularity. If removing
context makes the viewer guess the relationship, restore it. Use Semantic
Co-presence to specify availability without prescribing a fixed screen arrangement.

## Semantic Co-presence

**Semantic Co-presence is an information availability requirement.** Objects,
evidence or dimensions must be jointly perceptible, directly relatable, reliably
comparable, or integrable without excessive recall at the relevant cognitive moment.
It does not mean the same screen, immediate simultaneous visibility or a fixed layout.

For a job involving multiple objects, identify:

1. What must be jointly available?
2. At what cognitive moment must it become jointly available?
3. Is simultaneous availability necessary, or can Focus precede Synthesis?
4. What identity, scale, units, definition, scope and evidence status must remain
   stable or explicitly reconciled for the later comparison to be valid?
5. What would the viewer otherwise need to remember or reconstruct?

Possible approaches include simultaneous availability; progressive understanding
followed by synthesis; an anchor retained as other objects join; or reconstructing
previously focused objects in a common comparison context. These are reasoning
possibilities, not a taxonomy, components or mandatory sequences.

**Comparison may require eventual co-presence, not immediate co-presence.** Three
complex objects may first need individual understanding, then a shared comparison
context with their identities and necessary evidence returned. Merely showing all
three at once can increase learning and attention burden. Conversely, successive
isolated views with no supported return leave comparison to memory.

Gate 4 specifies this semantic availability requirement over the viewing path.
If achieving it needs a State split or a different dependency structure, use the
feedback loop with Gate 3. Do not prescribe three columns, shared axes, an overlay,
a toggle, animated convergence or a static overview. Gate 5 realizes the semantic
requirement in the base artifact; actual transitions and temporal/motion orchestration
belong to Gate 6. Focus and co-presence can be staged without defining animation here.

## Uncertainty and interaction need

### Editorial Ownership & Guardrail Separation

The final artifact must speak in a coherent, natural and accountable presenter voice.
Evidence Governance constrains expression; it should not become the expression.
Keep internal claim types, eligibility, provenance and Unsupported Reading controls
inspectable, but do not routinely print them as audience headings, badges or repeated
disclaimers. Ask whether a competent presenter would naturally say the sentence.

Preserve necessary uncertainty; eliminate repetitive defensive prose. Place material
limits at the judgment they affect, using precise wording, definitions and concrete
missing information. In a short artifact, one or two meaningful summary qualifications
will often suffice; this is not a global count limit. Local limitations still belong
where omission would mislead. Source or Evidence Inspection can expose the reasoning
record without turning Audience Mode into a visible ledger.

Natural paraphrases remain Presenter Framing with identifiable premises. Editorial
fluency must not promote hypotheses, revive excluded claims or imply comparable
measurements. Removing repeated labels does not remove underlying identity or status.

**Uncertainty must survive representation.** Distinguish observed, inferred,
proposed, partial, unverified and incomplete where they affect the claim. Explicit
status wording, a separated hypothesis, or a stated missing link can make the
boundary perceptible; final styling is deferred. Do not give a Proposal the same
unqualified certainty as an established mechanism. Source locators can support later
Evidence Mode; essential uncertainty must remain in Audience Mode itself.

**Interaction must solve a cognitive problem.** Identify a need only when static
representation is insufficient or burdensome: reveal, inspect, compare, switch
perspective, drill into evidence or return to overview. Record the problem and what
must remain understandable without the interaction. An optional evidence inspection
must not hide the limitation needed to interpret the primary claim. If static
expression suffices, record that no interaction is needed. Do not design controls,
events, transitions or animation here.

## Supported Meaning / Unsupported Reading handoff

For every important expression decision, specify **Supported Meaning**: what the
viewer should correctly obtain, grounded in the referenced evidence. Where a material
misreading risk exists, also specify **Unsupported Reading to Avoid**: the tempting
conclusion the evidence does not support. These are semantic constraints, not visual
implementation instructions. Do not invent generic risks merely to fill a field.

Consider ordering, emphasis, connection, proximity, symmetry, scale and familiar
visual conventions, including implications a later animation might introduce.
For example:

- Different proposal trade-offs do not establish a recommended middle option,
  left-to-right ranking, magnitude by area, or equal certainty with measured results.
- Two candidate explanations do not establish A → B, proven joint causation or
  equal contribution merely because they are connected or symmetric.
- Three process states do not establish a uniform, certain chronological sequence.

The downstream builder must know what to build, what meaning to preserve and what
misleading interpretation to avoid. If the main encoding contradicts the boundary,
change it; do not rely on a small disclaimer. Different implementations are valid
if they preserve those constraints: Universal Principles, Conditional Forms.

## Minimal Expression Plan

Use a concise note for important Scenes/States, not a mandatory JSON or fixed form.
Ensure the following are understandable, combining entries when useful:

- Cognitive Job and Relationship to Perceive, linked to the narrative node.
- Supported Meaning and its evidence basis.
- Expression Function and Candidate Representation Logic, including a candidate
  Representation Mode and why it reduces cognitive work.
- Attention Roles: Primary Signal, Supporting Context and suppressed/deferred detail.
- Semantic Co-presence Requirement: what is available when, and what stays stable.
- Evidence / Uncertainty Boundary.
- Unsupported Reading to Avoid where material risk exists.
- Interaction Need, or why static expression suffices.
- Return Anchor: identity, evidence and context that must survive return.

Gate 3 owns dependencies and viewing-path structure. Gate 4 owns semantic requirements,
attention, co-presence and expression constraints, and can send local structural
feedback to Gate 3. Gate 5 implements the Base Artifact preserving Supported Meaning,
Attention Priority, Semantic Co-presence and Unsupported Reading constraints. Gate 6
handles actual transition, motion, object continuity, progressive convergence and
temporal orchestration. Gate 7 considers Signature Expression. This handoff does
not authorize implementation, styling or any later Gate.

## Three tiny synthetic sanity examples

These are conceptual examples, not a full Trial, rendered designs or behavior tests.

**A · Compare proposals.** Job: understand trade-offs among three duty arrangements.
Function: Compare, supported by Qualify. Mode: an aligned comparison frame showing
who first responds, how escalation works and the stated staffing requirement for
each option. Keep proposal status and unmeasured response time visible. Suppress
background anecdotes; return to the same option identities in synthesis. Alignment
removes cross-description matching; no ranking, proportional size or presumed winner.
Static comparison is sufficient; the final shape need not be a table.

**B · Parallel explanations.** Job: distinguish observations from possible explanations
for complaints. Function: Relate, supported by Qualify. Mode: structured parallel
accounts, each pairing the relevant complaint category with a candidate explanation
and its missing linkage. Return to the shared observed phenomenon for synthesis;
keep category definitions and the possibility of unexplained cases present. Do not
connect the candidates as a causal chain or present them as proven joint causes.
Shared placement does not establish equal plausibility. Static text is sufficient.

**C · Evidence and interpretation.** Job: understand a recorded improvement without
assuming its cause. Function: Evidence, supported by Distinguish. Mode: an annotated
evidence excerpt linked to its bounded interpretation in the plan's semantic grouping.
The recorded outcome, measurement scope, proposed explanation and known confounder
must be available together. Suppress irrelevant activity counts. Return to the same
measure in synthesis. No causal arrow, invented confidence percentage or economic
benefit. Detailed source inspection may be useful later, but the causal uncertainty
cannot depend on opening it; the primary explanation works statically.

## Minimal sanity and stop

Check only: representation follows cognitive need; implied relationships are supported;
remembering/matching/inference burden is reduced; Focus/Synthesis/Return have an
expression role; uncertainty survives; no blocker likely to cause costly Gate 5 rework.
Stop when sufficient. No scoring, independent judge, full regression or broad audit.

For this architecture refinement, check only that the feedback loop distinguishes
representation from granularity problems, co-presence is not same-screen layout,
Focus can precede Synthesis, the handoff preserves both Supported Meaning and
Unsupported Reading constraints, and Gate boundaries hold. This is targeted
consistency review, not a Trial or evidence of behavioral reliability.

Still flexible: mode names, plan granularity, co-presence choices, density and whether
interaction is warranted. A subsequent authorized Gate 4 Trial can examine how these
requirements work in practice; do not start it as part of this refinement.
