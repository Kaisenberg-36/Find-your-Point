# Gate 2 · Narrative Logic Diagnosis & Cognitive Spine

**Runtime scope:** apply the continuation rule in [SKILL.md](../SKILL.md#runtime-authorization-and-continuation).
A full-briefing request authorizes necessary downstream stages. Stage-local stop/Trial
instructions below bound single-stage development requests; they do not require
fresh user approval during an already authorized briefing.

**Status: WORKING FREEZE.** Use when Gate 2 is explicitly authorized. This is a reasoning
model, not a fixed template, serialized schema or validated general-purpose engine.
Stop before Gate 3 Narrative Architecture: no sections composed, scenes, states,
page sequence, scripts, visual design or artifact generation.

## Purpose and input

Which material carries communication value, and which logic helps this audience
reach the intended understanding, judgment or action readiness?

These are independent possible objectives, not a required progression. An
understanding-only task is complete at understanding. Executive audiences do not
imply decision requests. Select logic for cognitive need, not executive tone.

**Audience Shift is not Subject Transformation.** An audience may need to understand
a stable contribution, unresolved problem, risk or choice. No business change needs
to have happened. Transformation is a useful narrative unit, not the mandatory center.

Use Gate 0's current operative context, audience and desired shift, plus Gate 1's
evidence-grounded material understanding. Eligible units include facts, results,
problems, risks, decisions, choices, changes, mechanisms, capabilities, constraints,
proposals and future implications. Preserve valuable non-transformation findings.
Reuse source/claim IDs, scope, uncertainties and counterevidence; do not build a
second ledger. Missing evidence remains missing. Narrative organization must not
upgrade evidence, including through implied causality or sequence.

An audience's starting belief must be known or explicitly assumed, not invented to
make the story persuasive. If the evidence cannot support the user's desired
conclusion, explain the limit and offer a narrower supported account or an alternative for
confirmation. Do not silently change the user's goal.

## Narrative Grammars: relationships, not slots

A grammar suggests relationships to examine. Arrows do not certify causality,
completeness, maturity or an obligatory presentation order.

| Grammar | Useful question and relational spine | Evidence boundary |
|---|---|---|
| A · Behavior / Market / Risk | Does an individual observation relate to a cohort, a signal and a wider map? Person → Cohort → Signal → Map | One person is not a representative cohort; repeated reports may share one source. A signal is not a proven trend or risk forecast. Use only supported levels. |
| B · Work / Management Evolution | How has work organization developed? Task → Coordination → Mechanism → System | Repeated action is not a mechanism; a local mechanism is not a system. Static work can remain relevant without invented evolution. |
| C · Problem Solving | What problem was addressed, how, with what result? Problem → Intervention → Result → Capability | A proposal is not an intervention, a result does not establish attribution, and a successful instance does not establish repeatable capability. |
| D · Strategy | What context makes a choice meaningful, what commitment follows, and what outcome is supported? Context → Choice → Commitment → Outcome | Options are not adopted choices; intent is not committed resources; anticipated outcomes remain conditional. |

These are not an exhaustive four-way classification. Result → Evidence → Value,
Problem → Evidence → Consequence, or Context → Choice → Rationale can be sufficient
for a task without transformation. Name the actual logic in plain language rather
than adding a new canonical Pattern every time a task differs. Unsupported stages
stay absent; a bounded fragment may be enough.

## Minimal diagnosis

1. **Anchor the cognitive objective.** State the communication context, desired audience shift,
   known/assumed starting understanding, and whether understanding, judgment, action readiness or a mixture is actually needed.
2. **Select units by their job.** For each consequential unit, identify whether it
   carries the main reasoning, supports a premise, qualifies a conclusion, serves a
   local question, or can be omitted. Evidence strength alone is not relevance.
   An inconvenient constraint may be essential; an impressive result may be irrelevant.
3. **Choose a Primary Pattern.** Consider context, audience, desired shift, evidence structure
   and current units together. Primary Pattern manages the overall cognitive direction. Explain how it serves that direction,
   and where it stops. Compare another plausible logic only if the choice matters;
   do not mechanically evaluate all four. If alternatives serve different audience
   goals, surface that difference instead of silently selecting a new goal.
4. **Use Local Patterns only where needed.** State the local question, the evidence
   it uses and its local cognitive job: explain, clarify, contextualize, compare,
   demonstrate, diagnose, support or qualify. Local Pattern must serve the global
   cognitive direction; it need not yield a local judgment. A local strategy discussion cannot turn a progress briefing
   into an unrequested funding pitch. No Local Pattern is required for symmetry.
5. **Build the Cognitive Spine.** Show the dependencies below, then remove links
   that require unsupported facts, hidden assumptions or unauthorized objectives.

Ask only when an unresolved choice materially changes the overall direction.
Otherwise provide a clearly provisional diagnosis, narrow it or preserve the gap.
If a unit has changed materially, revisit that unit or the affected Gate 0 decision;
do not restart all prior Gates.

## Cognitive Spine and provisional working note

Audience Before → Required Cognitive Transition(s) → Audience After.

Transitions may be understanding, reframing, differentiation, synthesis, recognition,
comparison, judgment, decision readiness or action readiness. Use only what the task
needs; do not automatically append evaluation, approval or action.
For each transition explain why it is needed here, which known gap it addresses,
which evidence supports it, what next understanding it enables, and whether going
further is authorized and necessary. STOP AT UNDERSTANDING when that is the goal.

This is a chain of necessary understanding, not an outline of slides or sections.
The first understanding may be a distinction, constraint or comparison basis, not a
historical before-state. Multiple units may support one link, and one unit may
qualify several links. Readiness to defer a decision pending evidence is legitimate.

Keep one compact working note, in memory unless persistence is needed:

- **Anchor:** context, authorized shift, known/assumed audience starting point.
- **Primary logic:** relational reasoning and why it fits; significant alternative
  and boundary if useful.
- **Spine:** required cognitive transitions and their dependencies; attach existing
  unit/claim IDs and evidence limits at the point they matter.
- **Local contributions:** optional local question → cognitive contribution → return to
  the global cognitive direction. Avoid disconnected mini-stories.
- **Open boundary:** unsupported links, material alternatives, required confirmation.

Field names and representation remain provisional. A spine link is not supported
merely because its endpoint claims are individually true: explain the relationship
between them. Keep known limitations on the main path if they constrain the intended understanding, judgment or readiness.

## Two compact synthetic examples

These examples illustrate reasoning, not executed behavior trials or real outcomes.

**Understanding only: a stable internal service.** Assume an executive onboarding
session asks only how a service unit contributes. Materials establish current
responsibilities and allocation rules, but no change or compensation benchmark.

Primary logic: responsibility → how the work operates → what its figures describe.
Audience Before: the session brief says responsibilities and allocation rules have
not been explained; do not infer hostility or a specific mistaken belief.
Next understandings: distinguish allocated revenue from work the unit controls,
then relate the available figures to those responsibilities. Audience After: can
explain the unit's role and the limits of its figures. Stop at understanding; no
judgment about compensation or proposal to change evaluation follows automatically.

**Mixed logic: deciding whether a local practice is ready to expand.** Assume the
user requests a rollout-readiness judgment. Evidence supports repeated local use,
reports quicker handling with confounders, and identifies unresolved accountability.

Primary logic: D · Strategy, limited to Context → Choice → Rationale; commitment and
future outcome are not established. A local C fragment explains the original problem,
intervention and observed result, keeping attribution uncertain. A local B fragment
explains what is repeatable and what still depends on individuals, stopping before
System. Both return to the same judgment: what supports expansion readiness and what
conditions remain unresolved. The spine establishes local scope first, then benefit
and its limits, then unresolved operating conditions, enabling a bounded choice.
It does not automatically recommend rollout or manufacture a capability claim.

## User output and stopping point

Present a concise diagnosis: recommended primary logic, Cognitive Spine, local
contributions where useful, evidence boundaries and any consequential user choice.
Do not expose the full selection worksheet. This output guides later architecture;
it does not compose it or authorize Gate 3.

Minimal sanity: distinguish Audience Shift from Subject Transformation; support
no-transformation and understanding-only tasks; Primary + Local Patterns must serve
the global cognitive direction; include only needed transitions, not forced A/B/C/D selection;
identify any blocker likely to cause costly downstream rework. Stop if sufficient.

Still flexible: unit granularity, names for partial logics, number of spine links,
when a local logic deserves explicit labeling, and the Gate 3 handoff format.
Next, trial one bounded task with a clear audience goal and evidence limits.

When Gate 3 is explicitly requested, hand off the current spine, cognitive objective,
known/assumed entry understanding, evidence-linked units and unresolved limits to
