# Experimental Alpha scope

This repository contains the Skill entry, required reasoning references and validator, dependency instructions, synthetic implementation examples, and screenshots of the English demonstration. Private inputs, private evals, development history and local environment files are excluded.

The examples demonstrate bounded behavior, not universal reliability. Screenshots show actual synthetic local rendering without customer material or third-party image assets. CLI installation checks cover file placement; they do not establish equivalent behavior across agents. The installed-copy continuation check used the same execution context, not an independent model.
